# Joel — Here. Almost.

A local demo of the photographic head-and-hands sprite. Built with React and the Sites vinext starter.

```sh
npm ci --ignore-scripts
npm run dev
```

Open the local URL printed by the server, normally http://localhost:3000.
The demo stays local; no Sites project or deployment has been created.

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm run test:render
```

See [the workspace README](../README.md) for cutout processing, masks, asset exports,
and reuse of `components/FloatingPortrait.tsx` in another React project.
